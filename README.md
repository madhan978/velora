# VELORA MEN — Frontend Storefront

A responsive React + Vite menswear storefront prototype. This project is frontend-only and uses mock product data plus browser LocalStorage.

## Requirements
- Node.js 18+ (recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Included
- Responsive home page and navigation
- Shop catalogue with category, size and price filters
- Search and sorting
- Product detail pages and size selection
- Cart with quantity controls and demo coupons
- Wishlist
- Checkout form and demo order confirmation
- Demo order history and tracking
- About, contact, FAQ, shipping, returns, privacy and terms pages
- LocalStorage persistence for cart, wishlist and demo orders

## Important limitations
This is a frontend demonstration only. There is no server, database, secure authentication, inventory validation, email delivery, payment gateway or real order processing. Prices and product availability are sample data. Do not use it to accept real orders or payments until a secure backend and real business policies are implemented.

Product photos are loaded from Unsplash and therefore require an internet connection. Replace them with licensed store photography before commercial launch.
